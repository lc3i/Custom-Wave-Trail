# <c-fff0ef>Custom</c> <c-ffe4e2>Wave</c> <c-ffd2cf>Trail</c>

This mod allows you to customize your Wave Trail in ways never imagined before (they were imagined before)

* Custom Trail Color
* Custom Trail RGB
* Solid Wave Trail
* Wave Trail Size
* Wave Trail Pulse Size
* No Wave Pulse
* No Wave Trail?
* Keep Wave Trail On Death
* No Regular Trail Behind

All settings are able to be enabled separately for player 1 and player2
